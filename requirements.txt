# Tunneler / YASARA ExternalPython dependencies.
#
# These are installed into a dedicated venv that yasara.ini's PythonPath points
# at, isolating YASARA's plugin python from Homebrew system-python churn (the
# recurring source of dependency breakage, e.g. the Tcl/Tk 9 + matplotlib issue).
#
# Build:   ./setup_venv.sh              (creates the venv, installs these, AND adds
#                                        the yasara .pth described below)
# Point:   yasara.ini -> PythonPath /Users/<you>/.yasara-venv/bin/python
#
# IMPORTANT: a plain `pip install -r requirements.txt` is NOT enough. A
# GUI-launched YASARA runs plugins in a clean environment that does NOT inherit
# your shell's PYTHONPATH, so the venv must be told where YASARA's `yasara`
# module lives. setup_venv.sh writes a .pth into the venv site-packages pointing
# at /Applications/YASARA.app/Contents/yasara/pym. Without it the plugin dies
# with "ModuleNotFoundError: No module named 'yasara'".
#
# Scientific stack pinned to the versions the Tunneler regression baselines were
# generated against, so detection output stays reproducible.
numpy==2.4.4
scipy==1.17.1
scikit-learn==1.8.0
shapely==2.0.4
# matplotlib must be >=3.9.2 for Tcl/Tk 9 support (older versions fail with
# "ImportError: Failed to load Tcl_SetVar" on the tkagg backend).
matplotlib==3.11.0
# For the user's other ExternalPython plugins (FoldSeek, bioprodict):
requests
pandas
